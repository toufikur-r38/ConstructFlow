# ConstructFlow — Requirements Documentation

This directory contains the initial requirements documents for the ConstructFlow project, based on the CSE 309 project topic proposal.

## Documents

1. [Requirements Elicitation Document](requirements-elicitation.md) — selected elicitation approach, technique comparison and justification, stakeholders, interview guide, and validation plan.
2. [Requirements Analysis Document](requirements-analysis.md) — problem analysis, functional and non-functional requirements, use cases, business rules, priorities, and traceability.
3. [Software Requirements Specification (SRS)](software-requirements-specification.md) — formal IEEE-style structure for scope, interfaces, system features, quality requirements, data, use cases, and acceptance criteria.

## Important note

These are initial drafts based on the proposal, not evidence of completed stakeholder interviews. Details not specified in the proposal are identified as assumptions, proposed requirements, or TBD items and should be validated with the course supervisor and representative users before implementation.
